5.1 Architecture des Fonctions

Une fonction regroupe un ensemble d'instructions sous un nom unique.

Déclarer ses Fonctions (`def`)

On utilise le mot-clé def suivi du nom de la fonction et de deux-points.

5.2 Implémentations

def saluer(nom="Étudiant"):
    return "Bonjour " + nom
