5.1 Créer ses propres Fonctions en R

1. Pourquoi créer des fonctions ?

Une fonction regroupe un ensemble d'instructions sous un nom unique et réutilisable. En R, le mot-clé pour définir une fonction est function :

# Syntaxe de base
nom_fonction <- function(paramètre1, paramètre2) {
  # corps de la fonction
  return(résultat)
}

2. Exemple concret — fonction carré

# Définition
carre <- function(x) {
  return(x ^ 2)
}

# Appel
carre(5)   # retourne 25
carre(1:4) # retourne 1 4 9 16 (vectorisé !)

3. Valeurs par défaut des paramètres

On peut donner une valeur par défaut à un paramètre. Si l'utilisateur ne précise pas cette valeur, la valeur par défaut est utilisée :

saluer <- function(nom = "Étudiant") {
  paste("Bonjour", nom)
}
saluer()           # "Bonjour Étudiant"
saluer("Aminata")  # "Bonjour Aminata"

4. La dernière valeur est renvoyée automatiquement

En R, return() est optionnel : la dernière expression évaluée dans la fonction est automatiquement renvoyée :

double <- function(x) x * 2  # return implicite
double(8)  # retourne 16
✦ R vs Python : En Python on utilise def pour définir une fonction. En R on utilise function avec l'opérateur d'assignation <-. La logique est la même, seule la syntaxe change !
