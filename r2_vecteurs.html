2.1 Les Objets R et les Vecteurs

1. Tout est objet en R

En R, tout est un objet : les variables, les fonctions, les données. Chaque objet possède un mode (son type) et une longueur (le nombre d'éléments qu'il contient).

ModeContenuExemple
numericNombres réelsx <- 3.14
logicalVrai / Fauxb <- TRUE
characterChaînes de textes <- "bonjour"
complexNombres complexesz <- 2+3i

2. Le Vecteur — unité de base de R

Contrairement à d'autres langages, R n'a pas de scalaire : un simple nombre est un vecteur de longueur 1. On crée des vecteurs avec la fonction c() (concaténation) :

  • v <- c(1, 2, 5, 9) → vecteur de 4 nombres
  • v <- c("Mali", "Sénégal", "Côte d'Ivoire") → vecteur de 3 chaînes
  • 1:10 → vecteur de 1 à 10 (raccourci pratique)

3. Accéder aux éléments d'un vecteur

On accède aux éléments avec les crochets [ ]. En R, les indices commencent à 1 (contrairement à Python) :

  • v[1] → premier élément
  • v[2:4] → éléments 2 à 4
  • v[c(1,3)] → éléments 1 et 3

4. Fonctions utiles sur les vecteurs

  • length(v) → longueur du vecteur
  • sum(v) → somme de tous les éléments
  • mean(v) → moyenne
  • max(v) / min(v) → maximum / minimum
  • sort(v) → tri croissant
✦ Particularité de R : Les opérations mathématiques sur les vecteurs s'appliquent élément par élément automatiquement. Par exemple, c(1,2,3) * 2 donne 2 4 6 sans boucle !

2.2 Manipulez les vecteurs R

Entrez vos propres valeurs séparées par des virgules et observez les calculs vectoriels en temps réel.

💻 Simulateur R — Vecteurs 
# Création d'un vecteur avec c()
v <- c(4,8,15,16,23,42)

# Informations sur le vecteur
length(v)    # nombre d'éléments
v[1]         # premier élément
sum(v)       # somme
mean(v)      # moyenne
max(v)       # maximum
min(v)       # minimum
v * 2        # multiplication vectorielle
