# 🚀 GUIDE DE PUBLICATION ABT CODE

## OPTION 1 — NETLIFY (le plus simple, recommandé)

### Étapes :
1. Allez sur https://netlify.com
2. Créez un compte gratuit (avec votre email)
3. Sur le tableau de bord, cliquez "Add new site" → "Deploy manually"
4. Glissez-déposez le DOSSIER ENTIER de vos fichiers ABT Code
5. Netlify vous donne automatiquement une URL comme :
   → https://abt-code.netlify.app

### Mise à jour automatique :
- Chaque fois que vous re-glissez le dossier mis à jour, le site se met à jour
- Ou connectez votre compte GitHub pour les mises à jour automatiques

---

## OPTION 2 — GITHUB PAGES (gratuit, avec historique)

### Étapes :
1. Créez un compte sur https://github.com
2. Créez un nouveau repository : "abt-code" (public)
3. Uploadez TOUS les fichiers HTML/CSS/JS
4. Settings → Pages → Source → "main" branch → Save
5. URL : https://votre-nom.github.io/abt-code

### Mise à jour :
- Modifiez un fichier → Commit → Le site se met à jour en 2 minutes

---

## OPTION 3 — VERCEL (très rapide)

1. https://vercel.com → "New Project"
2. Importez depuis GitHub ou uploadez directement
3. URL automatique : https://abt-code.vercel.app

---

## ⚠️ IMPORTANT — Nom de domaine personnalisé

Si vous voulez une URL comme "abt-code.ml" ou "abt-code.com" :
- Freenom.com → domaines gratuits (.ml, .tk, .ga)
- Namecheap.com → domaines payants (~10$/an)
- Connectez votre domaine dans les settings Netlify/Vercel
