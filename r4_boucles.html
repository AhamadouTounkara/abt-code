4.1 Les Structures Répétitives en R

1. La boucle for

La boucle for en R parcourt les éléments d'un vecteur un par un. Sa syntaxe est :

for (variable in vecteur) {
  # instructions répétées
}

Exemple classique avec 1:n pour générer une suite de nombres :

for (i in 1:5) {
  print(i)
}
# Affiche : 1 2 3 4 5

2. La boucle while

La boucle while répète tant qu'une condition est vraie. Elle est utile quand on ne connaît pas à l'avance le nombre d'itérations :

x <- 1
while (x <= 5) {
  print(x)
  x <- x + 1
}

3. La boucle repeat + break

R possède aussi une boucle repeat qui tourne indéfiniment jusqu'à ce qu'un break l'interrompe. C'est utile pour les algorithmes numériques itératifs :

i <- 0
repeat {
  i <- i + 1
  if (i >= 5) break
}
✦ Particularité R : R encourage la vectorisation plutôt que les boucles. sum(1:100) est bien plus rapide que d'écrire une boucle for pour additionner 100 nombres ! Utilisez les boucles uniquement quand la vectorisation n'est pas possible.

4. Suite de Fibonacci — exemple concret

Calculer les n premiers termes de la suite de Fibonacci (0, 1, 1, 2, 3, 5, 8...) avec une boucle for :

n <- 10
x <- c(0, 1)
for (i in 3:n) x[i] <- x[i-1] + x[i-2]
print(x)
