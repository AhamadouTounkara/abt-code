Un compte GitHub est requis

GitHub Codespaces nécessite un compte GitHub gratuit. Créer un compte → · Ensuite 60 heures gratuites par mois.

📖 Comment utiliser GitHub Codespaces
1
Créer un compte GitHub
Va sur github.com/signup — c'est gratuit. Entre ton email, un mot de passe et un nom d'utilisateur.
2
Créer un repository
Une fois connecté, clique "New" → nomme ton repository (ex: mes-projets-abt) → "Create repository".
3
Ouvrir un Codespace
Dans ton repository, clique le bouton vert "Code" → onglet "Codespaces" → "Create codespace on main".
✓
VS Code s'ouvre dans le navigateur !
Tu as maintenant VS Code complet avec terminal Linux. Tape python3 --version dans le terminal pour vérifier.
💡 Astuce : Tu peux aussi ouvrir directement github.com/codespaces/new pour créer un Codespace sans repository.
