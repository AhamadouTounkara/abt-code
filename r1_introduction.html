LANGAGE R

1.1 Présentation du langage R

1. Qu'est-ce que R ?

R est un langage de programmation libre et gratuit spécialement conçu pour les calculs statistiques, l'analyse de données et la visualisation graphique. Il est utilisé dans les universités, les laboratoires de recherche et les entreprises du monde entier.

💡 Pourquoi apprendre R ?
R est particulièrement puissant pour les applications mathématiques et statistiques. Parmi ses caractéristiques clés : langage basé sur la notion de vecteur, pas de déclaration obligatoire des variables, programmes courts et temps de développement très rapide.

2. Les interfaces pour utiliser R

  • Console R : invite de commande simple où l'on tape des expressions directement.
  • RStudio : environnement de développement intégré (IDE) très populaire — c'est l'outil recommandé pour débuter.
  • R en ligne : des sites comme replit.com ou rdrr.io permettent d'exécuter du R sans installation.

3. Première session de travail

Dans R, on tape des expressions à la ligne de commande et l'interpréteur les évalue immédiatement. Le signe > est l'invite de commande R :

  • > 2 + 3 → affiche [1] 5
  • > x <- 7 → crée la variable x avec la valeur 7 (opérateur d'assignation <-)
  • > x → affiche [1] 7

4. Commentaires dans R

Un commentaire commence par le symbole #. Tout ce qui suit ce symbole sur la même ligne est ignoré par R.

5. Obtenir de l'aide

Pour consulter la documentation d'une fonction (par exemple sum), on tape ?sum ou help(sum) dans la console.

1.2 Premières expressions R

Modifiez les valeurs et observez ce que R calcule. C'est ainsi qu'on apprend : en exécutant et en observant.

💻 Simulateur R — Calculs & Variables 
# Assignation de variables
x <- 7
y <- 3

# Opérations de base
x + y    # addition
x - y    # soustraction
x * y    # multiplication
x / y    # division
x ^ 2   # puissance
sqrt(x)  # racine carrée
