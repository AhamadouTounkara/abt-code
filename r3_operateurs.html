4. Structures de contrôle — if / else

En R, la structure conditionnelle s'écrit ainsi :

if (condition) {
  # code si vrai
} else {
  # code si faux
}
✦ Astuce R : La fonction ifelse(condition, val_si_vrai, val_si_faux) est une version vectorisée très pratique : elle s'applique à tout un vecteur en une seule ligne !

3.2 Testez les opérateurs R

Modifiez les valeurs et observez le résultat de chaque opération.

💻 Simulateur R — Opérateurs & Fonctions 
# Opérations sur a et b
a <- 17
b <- 5

a + b; a - b; a * b
a / b          # division réelle
a %% b         # modulo (reste)
a %/% b        # division entière
a ^ b          # puissance
sqrt(a)        # racine carrée
a > b          # comparaison
