2.1 Mécanismes de Stockage et Typage Dynamique

1. Qu'est-ce qu'une Variable ?

En programmation, une variable est un espace nommé dans la mémoire RAM de l'ordinateur. Elle permet de stocker une donnée pour la réutiliser plus tard. En Python, l'affectation se fait avec le signe égal (=).

2. Types de Données essentiels

TypeNom AnglaisExemple
intInteger (Entier)age = 25
floatFloat (Décimal)prix = 19.99
strString (Texte)nom = "Ahmad"
boolBoolean (Logique)valide = True

3. Le Casting (Conversion)

Parfois, il faut transformer un type en un autre. Par exemple, convertir du texte en nombre pour faire un calcul. On utilise les fonctions int(), float() ou str().
